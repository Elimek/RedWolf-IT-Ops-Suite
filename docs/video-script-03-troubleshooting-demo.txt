# Video Script 03: Troubleshooting Demo (3 Minutes)

## Scene Breakdown

### [0:00-0:15] Setup
**[Camera: Terminal and browser side by side]**
"In this demo, I'll walk through diagnosing and resolving three common IT issues using the RedWolf Ops Suite."

### [0:15-1:15] Scenario 1: Printer Not Working
**[Camera: User reports "3rd floor printer won't print"]**

**[0:15-0:30] Step 1: Check Network
"First, let's use the Network Scanner to verify the printer is on the network."
**[Action: Open network_scanner.php, enter printer IP range]**
"The printer at 192.168.1.50 shows as online with port 9100 open. So the network connection is fine."

**[0:30-0:50] Step 2: Check Error Codes
"Now let's check the printer error code lookup."
**[Action: Open printer_config.html, Error Code tab, search "50.2"]**
"Error 50.2 on HP printers means a fuser temperature error. The fix is to power cycle the printer and check the fuser."

**[0:50-1:15] Step 3: Log and Escalate
"I'll log this in the audit trail and notify the user."
**[Action: Show audit_log entry]**

### [1:15-2:15] Scenario 2: High CPU Alert
**[Camera: Alert notification appears]**

**[1:15-1:30] Step 1: Check Dashboard
"An alert just fired: CPU usage above 90%. Let's check the monitoring dashboard."
**[Action: Open dashboard.php, show red CPU indicator]**
"The dashboard confirms sustained high CPU for the last 3 readings."

**[1:30-1:50] Step 2: Identify the Process
"The process table shows a runaway PHP process consuming 85% CPU."
**[Action: Highlight the process in the table]**

**[1:50-2:15] Step 3: Use Fault Simulator
"Let's use the fault simulator to practice this scenario and then restore."
**[Action: Click "Restore All", show CPU dropping back to normal]**

### [2:15-3:00] Scenario 3: AI Ticket Classification
**[Camera: New ticket submitted]**

**[2:15-2:45] Step 1: Auto-Classify
"A new ticket comes in. Let's use the AI classifier."
**[Action: Open classifier.html, paste ticket text, click classify]**
"The classifier identifies this as a 'network' issue with 92% confidence and high priority."

**[2:45-3:00] Wrap-up
"All three issues resolved in under 3 minutes using the integrated toolset."
