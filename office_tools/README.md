# Office Support Tools

IT support toolkit for daily office operations.

## JD Alignment
- Demonstrates **network troubleshooting** skills
- Shows understanding of **office IT support** (printers, VPN)
- Proves **security awareness** (input validation, audit logging)

2. **Printer Config Helper** - IP calculator, port check, error codes
3. **VPN Status Checker** - OpenVPN/WireGuard detection and management
